> **Engineering OS · [venzari.co/code](https://venzari.co/code)**

```sh
```

Not an AI coding assistant. The governance system that decides when and how AI is allowed to interact with your codebase.

AI coding tools suggest code. VENZARI CODE enforces a lifecycle — 13 operating modes, each with different permissions and evidence requirements, backed by persistent memory, loop detection, and an immutable audit trail.

### 13 Operating Modes

```
Discover → Plan → Implement → Validate → Review → Repair → Commit
                ↓
Advisor | Handoff | Audit | Benchmark | Migration | Release
```

Each mode enforces different tool permissions. **Validate mode** requires actual test output — not the AI's claim that tests pass. **Commit mode** is the only mode where git operations are allowed. Every tool call in every mode is logged to an immutable evidence record that follows the commit.

### Memory That Doesn't Forget

Three-signal retrieval — every memory is indexed three ways:

| Signal | Speed | Use case |
|--------|-------|----------|
| Vector embeddings | 50ms | Semantic: *"what did we discuss about billing?"* |
| BM25 full-text | 10ms | Exact: code snippets, precise phrases |
| PageRank graph | 5ms | Importance: most-referenced facts surface first |

### 2,212 Skills

**11 S-tier** (flagship) · **522 A-tier** (high quality) · **1,679 B-tier** (community)

Invoked automatically based on context. No manual selection needed.

### The Learning Loop

Every night at 3am:
1. Repeated patterns → new skills created automatically
2. Usage signals → underperforming skills improved
3. Interaction history → your context model updated
4. Old interactions compressed → key facts retained
