## Questions People Actually Ask

**"Do I need a GPU?"**
No. ENGINE runs on CPU-only machines — 4 cores and 8GB RAM is the floor (the installer warns you below that). A GPU makes it dramatically better: NVIDIA with 8GB+ VRAM accelerates local inference to real-time. Without one, you get the full system running on CPU models, which works, and which is still better than sending your data to someone else's server.

**"What happens when my internet goes down?"**
Everything keeps working. Once installed, ENGINE does not require a connection. The models are local. The memory is local. The dashboard is local. Only the license check touches the network, and it has a 24-hour offline grace period. We designed for the worst case: VENZARI could cease to exist tomorrow, and your system would still run. That's the point of ownership.

**"How long does installation actually take?"**
Twenty minutes for a full ENGINE install on a decent VPS, including model pulls. The Together install does the whole stack. The installer doesn't ask you to babysit it — 11 pre-flight checks run in parallel before a single question is asked, so the failures surface immediately instead of nine steps in.

**"Can my data leak?"**
Architecturally, no. Not "we promise not to" — there is no code path that sends your data to us. The installer downloads the software, the models are pulled from public model registries, and the runtime speaks to itself. If you block all outbound traffic after install, it keeps working. That's a testable claim, not a marketing one.

**"What if I want to move to a different model later?"**
That's the point of the router. 13 supported providers, local models always tried first, cloud fallbacks only if you configure them. Swap the model, keep the memory. Your conversations and your context stay in your database regardless of which model is answering.

**"Is this just a wrapper around an API?"**
No. ENGINE runs local models through Ollama and LiteLLM. Together routes CODE's inference to that local gateway and never contacts `ai.venzari.xyz`. The AI AGENT tries local Ollama first and only reaches for a cloud provider when you've explicitly configured one as a fallback. The default configuration sends nothing anywhere.

**"Will my team actually use it, or is it another tool nobody opens?"**
The AI AGENT is the one people open — because it meets them where they already are. Telegram, Slack, Discord, email, a widget on your site, a webhook. Nobody has to learn a new tool; they talk to the agent in the channel they already live in, and it's the same agent with the same memory in every one of them.

**"What about CODE — isn't this over-engineering for a small team?"**
Start with Discover and Plan modes. They're read-only and document-only. A three-person team gets the codebase discovery and the written plans for free, without changing a line. When you're ready, Implement respects the plan's scope so the AI can't wander off and start editing files you never approved.
