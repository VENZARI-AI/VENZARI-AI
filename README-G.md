## ⚙️ VENZARI CODE — Engineering OS

> **[venzari.co/code](https://venzari.co/code)** · *The governance layer above AI*

### What It Is

AI coding assistants are suggestion machines. No memory. No governance. No evidence trail. You get a commit that says "AI-assisted" and that's all it says.

VENZARI CODE is the **operating system** above AI models. 13 operating modes. Each with different tool permissions. Each with different evidence requirements. Every action logged, timestamped, immutable.

> [!TIP]
> CODE and Copilot coexist. Copilot is a suggestion tool. CODE is the OS that governs when suggestions interact with your codebase.

### The 3-Stage Installer

```
Stage 1: 11 Pre-Install Checks (parallel, before any wizard question)
─────────────────────────────────────────────────────────────────
 ✓ RAM (fail <8GB)
 ✓ Disk (fail <60GB)
 ✓ CPU (warn <4 cores)
 ✓ OS (Ubuntu 22.04/24.04 only)
 ✓ Container runtime (installed + running)
 ✓ Ports (80, 443, 3000, 5432, 6379 available)
 ✓ Internet (required for install)
 ✓ Sudo access
 ✓ Existing install detection
 ✓ GPU detection (optional, NVIDIA drivers)
 ✓ Python 3.10+

Any failure stops with exact fix instructions. No partial states.


Stage 2: 7-Question Wizard (configures what can't be auto-detected)
─────────────────────────────────────────────────────────────────
 1. Server identity (domain or IP)
 2. License key (validates tier + seats)
 3. AI provider preference (local-only | local+cloud | cloud-only)
 4. Model selection (hardware-adaptive recommendations)
 5. SSL mode (auto Let's Encrypt | manual cert | HTTP only)
 6. Telemetry (anonymous install success ping yes/no)
 7. Optional add-ons (voice, custom training, workflows)

Everything else is auto-detected.


Stage 3: 17-Step Hardware-Customized Plan (from VENZARI installer service)
─────────────────────────────────────────────────────────────────────────
 Your hardware profile + license → installer service
     ↓
 Returns 17-step plan customized for your machine
     ↓
 Binary (verified) → models → services → health → SSL → wiring

 Resumable: Step 9 fails? Run resume-repair command.
 Skips steps 1–8 (complete), retries from 9.

 2,301 automated tests back every step.
```
