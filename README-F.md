## The Installer: Why It Matters

The biggest barrier to private AI infrastructure is not cost. It is complexity. Building your own stack takes 3–6 months and a dedicated engineering team — which is why most mid-market companies either don't do it or compromise with cloud AI.

VENZARI's installer removes that barrier:

**11 pre-flight checks** catch every problem before installation begins. RAM, disk, ports, Docker, internet, sudo access — all checked in parallel. Any failure gives you the exact fix instruction.

**7 wizard questions** configure everything that can't be auto-detected: server identity, license key, AI provider preference, model selection, add-ons.

**17 worker-driven steps** execute a hardware-customized plan from `installer.venzari.xyz`. Your machine's profile determines which models, which configuration, which performance settings. Not a generic script — a plan built for your specific hardware.

**2,301 automated tests** back every step. The installer has been tested against hundreds of hardware configurations, network conditions, and edge cases.

**Resumable:** `venzari-engine install --repair` skips completed steps and retries from the failure point. A network interruption at step 12 doesn't restart from step 1.

**Offline after install:** once the system is running, it requires no ongoing internet connection. Cloud AI disappears when your connection does. VENZARI ENGINE keeps running.
