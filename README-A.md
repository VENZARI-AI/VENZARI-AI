## You've Been Renting Your AI

Every time you send a prompt to a cloud AI service, three things happen:

1. **Your data leaves your control.** It travels to someone else's server. Their privacy policy promises to protect it — but policies change, companies get acquired, and legal requests override promises.

2. **You pay per token.** Every word in, every word out, billed individually. The more you use it, the more it costs. There is no ceiling. There is no ownership. You are renting intelligence by the sip.

3. **It forgets you.** Close the tab. Open it tomorrow. Start from zero. Re-explain your project, your codebase, your preferences, your decisions. Every. Single. Time.

VENZARI is not a better cloud AI. VENZARI is a different category entirely.

## The VENZARI Installer

The installer is not a side note. It is the product.

Most AI infrastructure requires 3-6 months and a dedicated engineering team. VENZARI's installer does it in 20 minutes with an office manager who knows SSH.

**Stage 1 — Pre-install checks (11 parallel, automatic):**
RAM (fail <8 GB, warn <16 GB) · Disk (fail <60 GB, warn <40 GB) · Ports 4001/11434/5432/6379 free · Docker installed + running · Internet connectivity · Sudo access · Existing install detection

**Stage 2 — Setup wizard (7 questions):**
Server identity · License key · AI provider preference (local-only, local + cloud, or cloud-only) · Model selection (hardware-adaptive) · Optional add-ons · Final confirmation

**Stage 3 — Worker-driven install plan (17 steps, hardware-customized):**
The installer sends your hardware profile to `installer.venzari.xyz`. The Worker returns a 17-step plan tailored to your hardware tier and license. Pre-install verification → binary download → model pulls → docker-compose → health checks → gateway config → SSL/nginx → ecosystem wiring → MCP registration → install ping.

**2,301 automated tests back the installer.** Every step has retry logic. The install is resumable: `venzari-engine install --repair` skips completed steps and retries from the failure point.
