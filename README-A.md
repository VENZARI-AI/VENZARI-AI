## ⚙️ VENZARI CODE — Engineering OS

> **[venzari.co/code](https://venzari.co/code)** · `see docs.venzari.co`

**Not an AI coding assistant. The OS that governs how AI touches your code.**

AI coding tools are powerful and ungoverned. They hallucinate, loop, and do unexpected things — with no record of what happened. VENZARI CODE is the governance layer: 13 operating modes enforce a workflow that mirrors how engineering actually works.

### The 13-Mode Lifecycle

<table>
<tr><td>

**Primary workflow:**

| Mode | What it enforces |
|------|-----------------|
| 🔍 **Discover** | Scan + read only. Zero writes. |
| 📋 **Plan** | Write a plan document. No code. |
| ⚒️ **Implement** | Execute within approved scope only. |
| ✅ **Validate** | Tests must pass — **actual output, not claims** |
| 👁️ **Review** | Read-only. Static analysis + security. |
| 🔧 **Repair** | Fix-only mode. Scope locked. |
| 📝 **Commit** | Git operations only. Evidence attached. |

</td><td>

**Secondary modes:**

| Mode | Purpose |
|------|---------|
| 🎯 **Advisor** | Analysis only, zero writes |
| 📤 **Handoff** | Structured session summary |
| 🔍 **Audit** | Review evidence records |
| 📈 **Benchmark** | Performance regression |
| 🔄 **Migration** | Large-scale changes |
| 🚀 **Release** | Full access + deploy |

</td></tr>
</table>

### Five Governance Components

- **SSOT Loader** — reads project rules before every action; AI operates within established patterns
- **Tool Guard** — per-mode allowlists enforced at system call level, not just prompts
- **Loop Detector** — 3 identical attempts without progress → escalate to human, stop
- **Evidence Collector** — every tool call logged: input, output, timestamp; immutable; follows commit
- **Context Assembler** — synthetic context window (<4,000 chars) with the most relevant project knowledge

## 🚀 The Installer

> **The installer is not a side note. It is the product.**

Most private AI infrastructure requires 3-6 months and a dedicated engineering team. VENZARI's installer does it in **20 minutes** with someone who knows SSH.

```
Stage 1: 11 parallel pre-install checks (RAM / Disk / Ports / the container runtime / Internet / Sudo)
```
