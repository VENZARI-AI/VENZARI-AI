## 🛠️ VENZARI CODE — 治理 AI 的工程操作系统

> **不是编码助手。是 AI 辅助开发运行的治理基础。**

| 每个人面临的问题 | VENZARI CODE 解决 |
|---|---|
| ✅ AI 自信地编写不能工作的代码 | ✅ 证据要求证明输出确实有效 |
| ✅ 陷入修复循环 | ✅ 循环检测在 3 次尝试时中断失控会话 |
| ✅ AI 所做的事没有问责制 | ✅ 每个工具调用记录到不可变的证据记录中 |
| ✅ 每个会话从零开始 | ✅ 持久内存在会话之间维护上下文 |
| ✅ AI "顺便"做意外的事情 | ✅ 每个模式的工具守卫限制 AI 在每个阶段可以做什么 |
| ✅ 无法在受监管环境中使用 AI | ✅ 正式的模式生命周期创建每个操作的可审计记录 |

**13 模式生命周期：** 发现 → 计划 → 实施 → 验证 → 审查 → 修复 → 提交 | 顾问 | 移交 | 审计 | 基准 | 迁移 | 发布

每种模式都有不同的能力和风险容忍度。将它们全部同等对待会导致问题。

> **不再有幻觉循环。不再有未审查的代码。不再有会话之间的上下文丢失。**

<details>
<summary>点击查看 13 种模式的详细信息</summary>

| 模式 | 能力 | 它防止什么 |
|---|---|---|
| **发现** | 扫描环境，读取项目结构 | 在不理解的情况下跳转到实施 |
| **计划** | 编写具体计划 — 要更改的文件、要采取的步骤 | 不符合架构的无计划实施 |
| **实施** | 在范围内执行批准的计划 | AI "顺便"做意外的事情 |
| **验证** | 测试必须通过 — 生成实际测试输出，而不是 AI 的声称 | 交付带有 AI 保证的损坏代码 |
| **审查** | 静态分析、代码质量、安全性 — 只读 | 未经审查的 AI 代码直接进入生产 |
| **修复** | 仅针对性修复模式 — 范围锁定到特定失败 | 修复期间的范围蔓延 |
| **提交** | 唯一允许 git 操作的模式 — 带有证据引用的结构化提交消息 | 部分工作、未提交的更改、混乱的历史 |
| **顾问** | 仅高级分析，无写入，无执行 | — |
| **移交** | 在会话结束时生成结构化移交文档 | — |
| **审计** | 审查会话证据记录、模式转换、安全事件 | — |
| **基准** | 受控测试执行以跟踪性能回归 | — |
| **迁移** | 大规模更改的完全写入+执行访问 | — |
| **发布** | 包括部署操作的完全访问 — 由证据控制 | — |

</details>

<details>
<summary>💡 为什么所有权很重要（结构性隐私）</summary>

> **"我们不只是说您的数据是私密的。您的数据在物理上无法离开您的硬件。"**

使用云 AI，供应商的隐私政策是一份法律文件，可能会更改、过期、被收购取代或被法律请求推翻。数据在您发送时就离开了您的控制。

使用 VENZARI ENGINE，数据从未离开客户的硬件是设计使然。不存在 VENZARI 可以访问它的架构。隐私保证是**结构性的，而不是合同性的**。

这对以下情况很重要：
- 有商业秘密担忧的公司
- 受监管行业（医疗保健、法律、金融）
- 有数据主权要求的国家的公司
- 客户在合同上禁止与第三方共享数据的公司

</details>

<details>
<summary>📦 安装程序 — Wow 因素（雇用您自己的 CTO）</summary>

**VENZARI 安装程序**不仅运行脚本。就像拥有自己的 VENZARI CTO 自动处理每个设置和配置步骤。

**阶段 1 — 预安装检查（自动，在任何向导问题之前）：** 11 个并行检查强制执行 RAM（≥8 GB 警告，<8 GB 失败）、磁盘（≥60 GB 警告，<60 GB 失败）、端口 4001/11434/5432/6379 空闲、Docker 已安装+运行、到 installer.venzari.xyz 的互联网连接、sudo 访问、现有安装检测。任何失败都会停止进程并准确告诉您要修复什么。

**阶段 2 — 设置向导（7 个问题）：** 服务器身份（域/IP、公司名称、管理员电子邮件）、许可证密钥验证、AI 提供商偏好（仅本地、本地+云回退支持 13 个提供商，或仅云）、硬件自适应模型推荐、可选附加组件（仅 Growth+）、最终确认。

**阶段 3 — 工作器驱动的安装计划（本地执行的 17 个步骤）：** 您的硬件配置文件发送到 `installer.venzari.xyz` 的 VENZARI 安装工作器。为您的硬件层和许可证定制的计划：二进制下载、AI 模型下载（快速+推理+嵌入）、docker-compose 编写和服务启动、每个服务的健康检查、网关配置（探测所有配置的 AI 提供商）、SSL 和 nginx 配置、生态系统布线（检测共同安装的 CODE/AI AGENT）、MCP 注册、匿名安装计数 ping。

每个步骤都有重试逻辑。安装可以在任何点**恢复**，使用 `venzari-engine install --repair` — 它跳过已完成的步骤并从失败点重试。

> **2,301 个自动化测试**涵盖每个步骤、每次重试、每次生态系统布线。

> **您在安装后关闭互联网连接，系统继续运行。**无按令牌计费。无云依赖。固定月度定价。

## ⚙️ VENZARI CODE

> [venzari.co/code](https://venzari.co/code) · *AI 之上的治理层*

### 它是什么

AI 编码助手是建议机器。无内存。无治理。无证据踪迹。您得到一个提交，上面写着"AI 辅助"，仅此而已。

VENZARI CODE 是 AI 模型之上的**操作系统**。13 个操作模式。每个都有不同的工具权限。每个都有不同的证据要求。每个操作都被记录、加时间戳、不可变。

> [!TIP]
> CODE 和 Copilot 共存。Copilot 是一个建议工具。CODE 是控制建议何时与您的代码库交互的操作系统。

### 13 模式生命周期

```
发现 → 计划 → 实施 → 验证 → 审查 → 修复 → 提交
                                                    ↗
顾问 · 移交 · 审计 · 基准 · 迁移 · 发布
```

| 模式 | 允许的工具 | 所需证据 |
|------|--------------|------------------|
| 发现 | 仅读取 | 观察报告 |
| 计划 | 仅写计划 | 计划文档 |
| 实施 | 范围内代码 | 工作代码 |
| 验证 | 运行测试 | **实际测试输出** |
| 审查 | 读取+扫描 | 审查报告 |
| 修复 | 仅修复失败 | 修复差异 |
| 提交 | Git 操作 | 提交+证据链 |
| 顾问 | 仅读取 | 分析文档 |
| 移交 | 仅摘要 | 移交文档 |
| 审计 | 读取证据 | 审计报告 |
| 基准 | 运行性能 | 基准数据 |
| 迁移 | 完全写入 | 迁移计划 |
| 发布 | 完全访问 | 发布证据链 |
