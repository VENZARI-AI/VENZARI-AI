## 🛠️ VENZARI CODE — Le Système d'Exploitation d'Ingénierie qui Gouverne l'IA

> **Pas un assistant de codage. Le substrat de gouvernance sur lequel fonctionne le développement assisté par IA.**

| Le Problème Que Tout Le Monde Rencontre | VENZARI CODE Résout |
|---|---|
| ✅ L'IA écrit du code avec confiance qui ne fonctionne pas | ✅ Les exigences de preuve prouvent que le résultat fonctionne réellement |
| ✅ Se bloque dans des boucles de correction | ✅ La détection de boucle interrompt les sessions incontrôlées à 3 tentatives |
| ✅ Aucune responsabilité pour ce que l'IA a fait | ✅ Chaque appel d'outil enregistré dans un registre de preuve immuable |
| ✅ Chaque session commence de zéro | ✅ La mémoire persistante maintient le contexte entre les sessions |
| ✅ L'IA fait des choses inattendues "en passant" | ✅ Les garde-fous d'outils par mode restreignent ce que l'IA peut faire à chaque étape |
| ✅ Impossible d'utiliser l'IA dans des environnements réglementés | ✅ Le cycle de vie de mode formel crée un registre vérifiable de chaque action |

**Le Cycle de Vie en 13 Modes :** Découvrir → Planifier → Implémenter → Valider → Réviser → Réparer → Confirmer | Conseiller | Transfert | Audit | Benchmark | Migration | Lancement

Chaque mode a des capacités et des tolérances au risque distinctes. Les traiter tous de la même manière est ce qui cause des problèmes.

> **Plus de boucles d'hallucination. Plus de code non révisé. Plus de perte de contexte entre les sessions.**

<details>
<summary>Cliquez pour voir les 13 Modes en Détail</summary>

| Mode | Capacité | Ce Qu'il Prévient |
|---|---|---|
| **Découvrir** | Analyse l'environnement, lit la structure du projet | Passer directement à l'implémentation sans comprendre |
| **Planifier** | Rédige un plan spécifique — fichiers à modifier, étapes à suivre | Implémentation non planifiée qui ne correspond pas à l'architecture |
| **Implémenter** | Exécute le plan approuvé dans la portée | L'IA faisant des choses inattendues "en passant" |
| **Valider** | Les tests doivent réussir — produit une sortie de test réelle, pas l'affirmation de l'IA | Livrer du code cassé avec l'assurance de l'IA |
| **Réviser** | Analyse statique, qualité du code, sécurité — lecture seule | Code IA non révisé allant directement en production |
| **Réparer** | Mode correction ciblée uniquement — portée verrouillée sur un échec spécifique | Dérive de portée pendant les corrections |
| **Confirmer** | Seul mode autorisant les opérations git — message de commit structuré avec références de preuves | Travail partiel, changements non committés, historique désordonné |
| **Conseiller** | Analyse de haut niveau uniquement, pas d'écriture, pas d'exécution | — |

<details>
<summary>💡 Pourquoi la Propriété Compte (Confidentialité Structurelle)</summary>

> **"Nous ne disons pas seulement que vos données sont privées. Vos données ne peuvent physiquement pas quitter votre matériel."**

Avec l'IA cloud, la politique de confidentialité d'un fournisseur est un document juridique qui peut changer, expirer, être remplacé par une acquisition, ou être annulé par une demande légale. Les données quittent votre contrôle au moment où vous les envoyez.

Avec VENZARI ENGINE, les données ne quittent jamais le matériel du client par conception. Il n'existe aucune architecture par laquelle VENZARI pourrait y accéder. La garantie de confidentialité est **structurelle, pas contractuelle**.

Cela compte pour :
- Les entreprises avec des préoccupations de secret commercial
- Les industries réglementées (santé, juridique, finance)
- Les entreprises dans des pays avec des exigences de souveraineté des données
- Les entreprises dont les clients interdisent contractuellement le partage de données avec des tiers

</details>

Tout échec arrête le processus et vous indique exactement quoi corriger.

**Étape 2 — L'assistant de configuration (7 questions) :** Identité du serveur (domaine/IP, nom de l'entreprise, email administrateur), validation de la clé de licence, préférence de fournisseur IA (local uniquement, local + secours cloud avec 13 fournisseurs pris en charge, ou cloud uniquement), recommandations de modèle adaptatives au matériel, modules complémentaires optionnels (Growth+ uniquement), confirmation finale.

**Étape 3 — Plan d'installation piloté par travailleur (17 étapes exécutées localement) :** Votre profil matériel envoyé au Travailleur d'Installation VENZARI sur `installer.venzari.xyz`. Plan personnalisé pour votre niveau de matériel et licence : téléchargement de binaire, téléchargements de modèles IA (rapide + raisonnement + embedding), écriture docker-compose et démarrage des services, vérifications de santé pour chaque service, configuration de passerelle (sonde tous les fournisseurs IA configurés), configuration SSL et nginx, câblage d'écosystème (détecte CODE/AI AGENT co-installé), enregistrement MCP, ping de comptage d'installation anonyme.

Chaque étape a une logique de nouvelle tentative. L'installation est **reprise à tout moment** avec `venzari-engine install --repair` — elle ignore les étapes terminées et réessaie depuis le point d'échec.
