## 🛠️ VENZARI CODE — Das Engineering-Betriebssystem, das KI Regiert

> **Kein Coding-Assistent. Das Governance-Substrat, auf dem KI-gestützte Entwicklung läuft.**

| Das Problem, dem Jeder Begegnet | VENZARI CODE Löst |
|---|---|
| ✅ KI schreibt selbstbewusst Code, der nicht funktioniert | ✅ Nachweispflichten beweisen, dass die Ausgabe tatsächlich funktioniert |
| ✅ Bleibt in Korrekturschleifen stecken | ✅ Schleifenerkennung bricht unkontrollierte Sitzungen bei 3 Versuchen ab |
| ✅ Keine Rechenschaftspflicht für das, was die KI getan hat | ✅ Jeder Tool-Aufruf in unveränderlichem Nachweisprotokoll aufgezeichnet |
| ✅ Jede Sitzung beginnt bei Null | ✅ Persistenter Speicher erhält Kontext über Sitzungen hinweg |
| ✅ KI macht unerwartete Dinge „nebenbei" | ✅ Pro-Modus-Tool-Wächter beschränken, was die KI in jeder Phase tun kann |
| ✅ KI kann nicht in regulierten Umgebungen verwendet werden | ✅ Formaler Modus-Lebenszyklus erstellt prüfbares Protokoll jeder Aktion |

**Der 13-Modus-Lebenszyklus:** Entdecken → Planen → Implementieren → Validieren → Überprüfen → Reparieren → Bestätigen | Berater | Übergabe | Audit | Benchmark | Migration | Release

Jeder Modus hat unterschiedliche Fähigkeiten und Risikotoleranzen. Sie alle gleich zu behandeln, verursacht Probleme.

> **Keine Halluzinations-Schleifen mehr. Kein ungeprüfter Code mehr. Kein Kontextverlust zwischen Sitzungen mehr.**

<details>
<summary>Klicken Sie, um die 13 Modi im Detail zu sehen</summary>

| Modus | Fähigkeit | Was Es Verhindert |
|---|---|---|
| **Entdecken** | Scannt Umgebung, liest Projektstruktur | Sprung zur Implementierung ohne Verständnis |
| **Planen** | Schreibt spezifischen Plan — zu ändernde Dateien, durchzuführende Schritte | Ungeplante Implementierung, die nicht zur Architektur passt |
| **Implementieren** | Führt genehmigten Plan im Rahmen aus | KI macht unerwartete Dinge „nebenbei" |
| **Validieren** | Tests müssen bestehen — erzeugt tatsächliche Testausgabe, nicht KIs Behauptung | Versand von defektem Code mit KIs Zusicherung |
| **Überprüfen** | Statische Analyse, Code-Qualität, Sicherheit — nur Lesen | Ungeprüfter KI-Code geht direkt in Produktion |
| **Reparieren** | Nur zielgerichteter Fix-Modus — Umfang auf spezifischen Fehler begrenzt | Umfangsausweitung während Korrekturen |
| **Bestätigen** | Einziger Modus, der Git-Operationen erlaubt — strukturierte Commit-Nachricht mit Nachweisreferenzen | Teilweise Arbeit, nicht committete Änderungen, unordentliche Historie |
| **Berater** | Nur Analyse auf hoher Ebene, keine Schreibvorgänge, keine Ausführung | — |
| **Übergabe** | Erstellt strukturiertes Übergabedokument am Sitzungsende | — |
| **Audit** | Prüft Sitzungsnachweise, Modusübergänge, Sicherheitsereignisse | — |
| **Benchmark** | Kontrollierte Testausführung für Performance-Regressionsverfolgung | — |
| **Migration** | Voller Schreib- + Ausführungszugriff für großflächige Änderungen | — |
| **Release** | Voller Zugriff einschließlich Deployment-Operationen — nachweisgekoppelt | — |

</details>

> **Ein einziger CLI-Befehl installiert ein komplettes privates KI-System auf Ihrer Hardware.**

<details>
<summary>⚙️ Was das Installierte System Bietet</summary>

| Funktion | Status | Was Es Tut |
|---|---|---|

| **Lokale Sprachsynthese & -Erkennung** | 🟢 Offline | Text-zu-Sprache und Sprache-zu-Text ohne Cloud-Latenz, keine Audio-Verarbeitung durch Dritte |
| **Geschäftsprozess-Automatisierung** | 🟢 Live | Vorgefertigte und benutzerdefinierte Workflows: geplante Berichte, E-Mail-Entwurf, CRM-Abfragen, Datenbanksuchen, API-Integrationen, Kalenderverwaltung |

| **Benutzerdefinierte Feinabstimmungs-Pipeline** | 🟢 Growth+ | Trainieren Sie ein benutzerdefiniertes KI-Modell auf eigenen Gesprächen und Domänenwissen des Unternehmens. Modell läuft lokal — Daten verlassen nie. |

</details>

<details>
<summary>💡 Warum Eigentum Wichtig Ist (Strukturelle Privatsphäre)</summary>

> **„Wir sagen nicht nur, dass Ihre Daten privat sind. Ihre Daten können physisch Ihre Hardware nicht verlassen."**

Bei Cloud-KI ist die Datenschutzrichtlinie eines Anbieters ein rechtliches Dokument, das sich ändern, auslaufen, durch eine Übernahme ersetzt oder durch eine rechtliche Anforderung außer Kraft gesetzt werden kann. Die Daten verlassen Ihre Kontrolle in dem Moment, in dem Sie sie senden.

Bei VENZARI ENGINE verlassen die Daten die Hardware des Kunden konstruktionsbedingt niemals. Es gibt keine Architektur, durch die VENZARI darauf zugreifen könnte. Die Datenschutzgarantie ist **strukturell, nicht vertraglich**.

Das ist wichtig für:
- Unternehmen mit Betriebsgeheimnis-Bedenken
- Regulierte Branchen (Gesundheitswesen, Recht, Finanzen)
- Unternehmen in Ländern mit Datensouveränitätsanforderungen
- Unternehmen, deren Kunden vertraglich das Teilen von Daten mit Dritten verbieten

</details>

<details>
<summary>📦 Installer — Der Wow-Faktor (Stellen Sie Ihren Eigenen CTO Ein)</summary>

Der **VENZARI INSTALLER** führt nicht nur ein Skript aus. Es ist, als hätten Sie Ihren eigenen VENZARI CTO, der jeden Konfigurations- und Setup-Schritt automatisch übernimmt.

**Phase 1 — Pre-Install-Checks (automatisch, vor jeder Assistentenfrage):** 11 parallele Prüfungen erzwingen RAM (≥8 GB Warnung, <8 GB Fehler), Festplatte (≥60 GB Warnung, <60 GB Fehler), Ports 4001/11434/5432/6379 frei, Docker installiert + läuft, Internetverbindung zu installer.venzari.xyz, sudo-Zugriff, Erkennung vorhandener Installation. Jeder Fehler stoppt den Prozess und sagt Ihnen genau, was zu beheben ist.

**Phase 2 — Der Setup-Assistent (7 Fragen):** Server-Identität (Domain/IP, Firmenname, Admin-E-Mail), Lizenzschlüssel-Validierung, KI-Anbieter-Präferenz (nur lokal, lokal + Cloud-Fallback mit 13 unterstützten Anbietern oder nur Cloud), hardware-adaptive Modellempfehlungen, optionale Add-ons (nur Growth+), endgültige Bestätigung.

**Phase 3 — Worker-gesteuerter Installationsplan (17 lokal ausgeführte Schritte):** Ihr Hardwareprofil wird an VENZARI Installer Worker bei `installer.venzari.xyz` gesendet. Plan angepasst für Ihre Hardware-Stufe und Lizenz: Binär-Download, KI-Modell-Downloads (schnell + Reasoning + Embedding), docker-compose-Schreiben und Service-Start, Integritätsprüfungen für jeden Service, Gateway-Konfiguration (testet alle konfigurierten KI-Anbieter), SSL- und nginx-Konfiguration, Ökosystem-Verkabelung (erkennt mitinstalliertes CODE/AI AGENT), MCP-Registrierung, anonymer Installations-Count-Ping.

Jeder Schritt hat Wiederholungslogik. Die Installation ist **an jedem Punkt wiederaufnehmbar** mit `venzari-engine install --repair` — sie überspringt abgeschlossene Schritte und wiederholt ab dem Fehlerpunkt.

> **2.301 automatisierte Tests** decken jeden Schritt, jede Wiederholung, jede Ökosystem-Verkabelung ab.

> **Sie schließen Ihre Internetverbindung nach der Installation und das System funktioniert weiter.** Keine Token-Abrechnung. Keine Cloud-Abhängigkeit. Feste monatliche Preise.

</details>
