## 🛠️ VENZARI CODE — O Sistema Operacional de Engenharia que Governa a IA

> **Não é um assistente de codificação. O substrato de governança sobre o qual o desenvolvimento assistido por IA é executado.**

| O Problema que Todos Enfrentam | VENZARI CODE Resolve |
|---|---|
| ✅ IA escreve código com confiança que não funciona | ✅ Requisitos de evidência provam que a saída realmente funciona |
| ✅ Fica preso em loops de correção | ✅ Detecção de loop quebra sessões descontroladas em 3 tentativas |
| ✅ Sem responsabilidade pelo que a IA fez | ✅ Cada chamada de ferramenta registrada em registro de evidência imutável |
| ✅ Cada sessão começa do zero | ✅ Memória persistente mantém contexto entre sessões |
| ✅ IA faz coisas inesperadas "de passagem" | ✅ Guardas de ferramentas por modo restringem o que a IA pode fazer em cada estágio |
| ✅ Não pode usar IA em ambientes regulamentados | ✅ Ciclo de vida de modo formal cria registro auditável de cada ação |

**O Ciclo de Vida de 13 Modos:** Descobrir → Planejar → Implementar → Validar → Revisar → Reparar → Confirmar | Consultor | Transferência | Auditoria | Benchmark | Migração | Lançamento

Cada modo tem capacidades e tolerâncias de risco distintas. Tratá-los todos da mesma forma é o que causa problemas.

> **Sem mais loops de alucinação. Sem mais código não revisado. Sem mais perda de contexto entre sessões.**

<details>
<summary>Clique para ver os 13 Modos em Detalhe</summary>

| Modo | Capacidade | O que Previne |
|---|---|---|
| **Descobrir** | Escaneia ambiente, lê estrutura do projeto | Pular para implementação sem entender |
| **Planejar** | Escreve plano específico — arquivos a mudar, passos a seguir | Implementação não planejada que não corresponde à arquitetura |
| **Implementar** | Executa plano aprovado dentro do escopo | IA fazendo coisas inesperadas "de passagem" |
| **Validar** | Testes devem passar — produz saída de teste real, não afirmação da IA | Enviar código quebrado com garantia da IA |
| **Revisar** | Análise estática, qualidade de código, segurança — somente leitura | Código de IA não revisado indo diretamente para produção |
| **Reparar** | Modo de correção direcionada apenas — escopo bloqueado em falha específica | Ampliação do escopo durante correções |
| **Confirmar** | Único modo permitindo operações git — mensagem de commit estruturada com referências de evidência | Trabalho parcial, mudanças não commitadas, histórico bagunçado |
| **Consultor** | Apenas análise de alto nível, sem escritas, sem execução | — |
| **Transferência** | Produz documento de transferência estruturado no final da sessão | — |
| **Auditoria** | Revisa registros de evidência de sessão, transições de modo, eventos de segurança | — |
| **Benchmark** | Execução de teste controlada para rastreamento de regressão de desempenho | — |
| **Migração** | Acesso completo de escrita + execução para mudanças em grande escala | — |
| **Lançamento** | Acesso completo incluindo operações de deploy — controlado por evidência | — |

<details>
<summary>💡 Por que a Propriedade Importa (Privacidade Estrutural)</summary>

> **"Nós não apenas dizemos que seus dados são privados. Seus dados fisicamente não podem sair de seu hardware."**

Com IA em nuvem, a política de privacidade de um fornecedor é um documento legal que pode mudar, expirar, ser substituído por uma aquisição ou ser anulado por uma solicitação legal. Os dados deixam seu controle no momento em que você os envia.

Com VENZARI ENGINE, os dados nunca deixam o hardware do cliente por design. Não existe nenhuma arquitetura pela qual VENZARI possa acessá-los. A garantia de privacidade é **estrutural, não contratual**.

Isso importa para:
- Empresas com preocupações de segredo comercial
- Indústrias regulamentadas (saúde, jurídico, finanças)
- Empresas em países com requisitos de soberania de dados
- Empresas cujos clientes proíbem contratualmente o compartilhamento de dados com terceiros

</details>

<details>
<summary>📦 Instalador — O Fator Wow (Contrate Seu Próprio CTO)</summary>

O **INSTALADOR VENZARI** não apenas executa um script. É como ter seu próprio CTO da VENZARI lidando com cada etapa de configuração e instalação — automaticamente.

**Estágio 1 — Verificações pré-instalação (automáticas, antes de qualquer pergunta do assistente):** 11 verificações paralelas impõem RAM (≥8 GB aviso, <8 GB falha), disco (≥60 GB aviso, <60 GB falha), portas 4001/11434/5432/6379 livres, Docker instalado + rodando, conectividade de internet para installer.venzari.xyz, acesso sudo, detecção de instalação existente. Qualquer falha interrompe o processo e diz exatamente o que corrigir.

**Estágio 2 — O assistente de configuração (7 perguntas):** Identidade do servidor (domínio/IP, nome da empresa, e-mail do administrador), validação de chave de licença, preferência de provedor de IA (apenas local, local + fallback de nuvem com 13 provedores suportados, ou apenas nuvem), recomendações de modelo adaptativas ao hardware, complementos opcionais (apenas Growth+), confirmação final.

**Estágio 3 — Plano de instalação dirigido por trabalhador (17 etapas executadas localmente):** Seu perfil de hardware enviado ao Trabalhador de Instalação VENZARI em `installer.venzari.xyz`. Plano personalizado para seu nível de hardware e licença: download de binário, downloads de modelo de IA (rápido + raciocínio + embedding), escrita de docker-compose e início de serviços, verificações de saúde para cada serviço, configuração de gateway (sonda todos os provedores de IA configurados), configuração SSL e nginx, cabeamento de ecossistema (detecta CODE/AI AGENT co-instalado), registro MCP, ping de contagem de instalação anônimo.

Cada passo tem lógica de repetição. A instalação é **retomável em qualquer ponto** com `venzari-engine install --repair` — pula passos concluídos e retenta a partir do ponto de falha.

> **2.301 testes automatizados** cobrem cada passo, cada repetição, cada cabeamento de ecossistema.

> **Você fecha sua conexão de internet após a instalação e o sistema continua funcionando.** Sem cobrança por token. Sem dependência de nuvem. Preços mensais fixos.

## ⚙️ VENZARI CODE

> [venzari.co/code](https://venzari.co/code) · *A camada de governança acima da IA*

### O que É

Assistentes de codificação de IA são máquinas de sugestões. Sem memória. Sem governança. Sem rastro de evidência. Você recebe um commit que diz "assistido por IA" e isso é tudo o que diz.

VENZARI CODE é o **sistema operacional** acima dos modelos de IA. 13 modos operacionais. Cada um com diferentes permissões de ferramentas. Cada um com diferentes requisitos de evidência. Cada ação registrada, com carimbo de data/hora, imutável.

> [!TIP]
> CODE e Copilot coexistem. Copilot é uma ferramenta de sugestões. CODE é o SO que governa quando sugestões interagem com sua base de código.
