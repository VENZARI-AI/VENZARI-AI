## 🛠️ VENZARI CODE — El Sistema Operativo de Ingeniería que Gobierna la IA

> **No es un asistente de código. Es el sustrato de gobernanza sobre el cual corre el desarrollo asistido por IA.**

| El Problema que Todos Enfrentan | VENZARI CODE Resuelve |
|---|---|
| ✅ La IA escribe código con confianza que no funciona | ✅ Los requisitos de evidencia prueban que el resultado realmente funciona |
| ✅ Se queda atascada en bucles de corrección | ✅ La detección de bucles rompe sesiones desbocadas a los 3 intentos |
| ✅ Sin responsabilidad por lo que hizo la IA | ✅ Cada llamada de herramienta registrada en registro de evidencia inmutable |
| ✅ Cada sesión empieza desde cero | ✅ La memoria persistente mantiene el contexto entre sesiones |
| ✅ La IA hace cosas inesperadas "de paso" | ✅ Los guardias de herramientas por modo restringen lo que la IA puede hacer en cada etapa |
| ✅ No se puede usar IA en entornos regulados | ✅ El ciclo de vida de modo formal crea un registro auditable de cada acción |

**El Ciclo de Vida de 13 Modos:** Descubrir → Planificar → Implementar → Validar → Revisar → Reparar → Confirmar | Asesor | Transferencia | Auditoría | Benchmark | Migración | Lanzamiento

Cada modo tiene capacidades y tolerancias de riesgo distintas. Tratarlos a todos igual es lo que causa problemas.

> **No más bucles de alucinación. No más código sin revisar. No más pérdida de contexto entre sesiones.**

<details>
<summary>💡 Por qué Importa la Propiedad (Privacidad Estructural)</summary>

> **"No solo decimos que tus datos son privados. Tus datos físicamente no pueden salir de tu hardware."**

Con IA en la nube, la política de privacidad de un proveedor es un documento legal que puede cambiar, expirar, ser reemplazado por una adquisición, o ser anulado por una solicitud legal. Los datos dejan tu control en el momento en que los envías.

Con VENZARI ENGINE, los datos nunca dejan el hardware del cliente por diseño. No existe ninguna arquitectura por la cual VENZARI pueda acceder a ellos. La garantía de privacidad es **estructural, no contractual**.

Esto importa para:
- Empresas con preocupaciones de secreto comercial
- Industrias reguladas (salud, legal, finanzas)  
- Empresas en países con requisitos de soberanía de datos
- Empresas cuyos clientes prohíben contractualmente compartir datos con terceros

</details>

<details>
<summary>📦 Instalador — El Factor Wow (Contrata Tu Propio CTO)</summary>

El **INSTALADOR VENZARI** no solo ejecuta un script. Es como tener tu propio CTO de VENZARI manejando cada paso de configuración — automáticamente.

**Etapa 1 — Verificaciones pre-instalación (automáticas, antes de cualquier pregunta del asistente):** 11 verificaciones paralelas imponen RAM (≥8 GB advertencia, <8 GB fallo), disco (≥60 GB advertencia, <60 GB fallo), puertos 4001/11434/5432/6379 libres, Docker instalado + corriendo, conectividad a internet a installer.venzari.xyz, acceso sudo, detección de instalación existente. Cualquier fallo detiene el proceso y te dice exactamente qué arreglar.

**Etapa 2 — El asistente de configuración (7 preguntas):** Identidad del servidor (dominio/IP, nombre de empresa, correo de administrador), validación de clave de licencia, preferencia de proveedor de IA (solo local, local + respaldo en nube con 13 proveedores soportados, o solo nube), recomendaciones de modelo adaptativas al hardware, complementos opcionales (solo Growth+), confirmación final.

**Etapa 3 — Plan de instalación dirigido por trabajador (17 pasos ejecutados localmente):** Tu perfil de hardware enviado al Trabajador de Instalación VENZARI en `installer.venzari.xyz`. Plan personalizado para tu nivel de hardware y licencia: descarga de binario, descargas de modelos de IA (rápido + razonamiento + embedding), escritura de docker-compose e inicio de servicios, verificaciones de salud para cada servicio, configuración de gateway (sondea todos los proveedores de IA configurados), configuración de SSL y nginx, cableado de ecosistema (detecta CODE/AI AGENT co-instalado), registro MCP, ping de conteo de instalación anónimo.

Cada paso tiene lógica de reintento. La instalación es **reanudable en cualquier punto** con `venzari-engine install --repair` — omite pasos completados y reintentos desde el punto de falla.
