## 🛠️ VENZARI CODE — AI を統治するエンジニアリング OS

> **コーディングアシスタントではありません。AI 支援開発が実行されるガバナンス基盤です。**

| 誰もが直面する問題 | VENZARI CODE が解決 |
|---|---|
| ✅ AI が機能しないコードを自信を持って書く | ✅ エビデンス要件が出力が実際に機能することを証明 |
| ✅ 修正ループにはまる | ✅ ループ検出が 3 回の試行で暴走セッションを中断 |
| ✅ AI が何をしたかの説明責任がない | ✅ すべてのツール呼び出しが不変のエビデンス記録に記録される |
| ✅ すべてのセッションがゼロから始まる | ✅ 永続的メモリがセッション間でコンテキストを維持 |
| ✅ AI が「ついでに」予期しないことをする | ✅ モードごとのツールガードが各段階で AI ができることを制限 |
| ✅ 規制された環境で AI を使用できない | ✅ 正式なモードライフサイクルがすべてのアクションの監査可能な記録を作成 |

**13 モードライフサイクル:** 発見 → 計画 → 実装 → 検証 → レビュー → 修復 → コミット | アドバイザー | 引き継ぎ | 監査 | ベンチマーク | マイグレーション | リリース

各モードには異なる能力とリスク許容度があります。すべてを同じように扱うことが問題を引き起こします。

> **幻覚ループはもうありません。レビューされていないコードはもうありません。セッション間のコンテキスト損失はもうありません。**

<details>
<summary>💡 所有権が重要な理由（構造的プライバシー）</summary>

> **「データがプライベートだと言うだけではありません。データは物理的にハードウェアを離れることができません。」**

クラウド AI では、ベンダーのプライバシーポリシーは、変更、期限切れ、買収による置き換え、または法的要求による無効化が可能な法的文書です。データを送信した瞬間に管理を失います。

VENZARI ENGINE では、設計上、データが顧客のハードウェアを離れることは決してありません。VENZARI がアクセスできるアーキテクチャは存在しません。プライバシー保証は**構造的であり、契約的ではありません**。

これが重要なのは:
- 企業秘密の懸念がある企業
- 規制された業界 (ヘルスケア、法律、金融)
- データ主権要件がある国の企業
- クライアントが契約上サードパーティとのデータ共有を禁止している企業

</details>

<details>
<summary>📦 インストーラー — Wow ファクター (独自の CTO を雇う)</summary>

**VENZARI インストーラー**は単にスクリプトを実行するだけではありません。独自の VENZARI CTO がすべてのセットアップと構成ステップを自動的に処理するようなものです。

**ステージ 1 — プレインストールチェック (自動、ウィザードの質問の前):** 11 の並列チェックが RAM (≥8 GB 警告、<8 GB 失敗)、ディスク (≥60 GB 警告、<60 GB 失敗)、ポート 4001/11434/5432/6379 空き、Docker インストール済み + 実行中、installer.venzari.xyz へのインターネット接続、sudo アクセス、既存インストール検出を強制。すべての失敗がプロセスを停止し、何を修正するかを正確に伝えます。

**ステージ 2 — セットアップウィザード (7 つの質問):** サーバー ID (ドメイン/IP、会社名、管理者メール)、ライセンスキー検証、AI プロバイダー設定 (ローカルのみ、ローカル + 13 のサポートされたプロバイダーでのクラウドフォールバック、またはクラウドのみ)、ハードウェア適応型モデル推奨、オプションのアドオン (Growth+ のみ)、最終確認。

**ステージ 3 — ワーカー駆動のインストールプラン (ローカルで実行される 17 ステップ):** ハードウェアプロファイルが `installer.venzari.xyz` の VENZARI Installer Worker に送信されます。ハードウェア層とライセンスに合わせてカスタマイズされたプラン: バイナリダウンロード、AI モデルダウンロード (高速 + 推論 + 埋め込み)、docker-compose 書き込みとサービス起動、各サービスのヘルスチェック、ゲートウェイ構成 (すべての構成された AI プロバイダーをプローブ)、SSL と nginx 構成、エコシステム配線 (共同インストールされた CODE/AI AGENT を検出)、MCP 登録、匿名インストールカウント ping。

各ステップにはリトライロジックがあります。インストールは `venzari-engine install --repair` で**任意のポイントで再開可能** — 完了したステップをスキップし、失敗ポイントから再試行します。

> **2,301 の自動化されたテスト**がすべてのステップ、すべてのリトライ、すべてのエコシステム配線をカバー。

> **インストール後にインターネット接続を閉じてもシステムは動作し続けます。**トークンごとの課金なし。クラウド依存なし。固定月額料金。
