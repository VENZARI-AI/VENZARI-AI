## The VenSTARI Installer — The Product Behind The Product

While competitors ask you to configure Docker compose files, manage environment variables, and troubleshoot model downloads for weeks — VENZARI installs itself.

The installer architecture has three stages:

**Stage 1 — Pre-install checks (automatic, before any wizard questions):** 11 parallel checks enforce RAM, disk, ports, Docker, connectivity, sudo — any failure stops the process and tells you exactly what to fix.

**Stage 2 — The setup wizard (7 questions):** Server identity, license validation, AI provider preference (local-only, local + cloud fallback with 13 providers, or cloud-only), hardware-adaptive model recommendations, optional add-ons, confirmation.

**Stage 3 — Worker-driven install plan (17 steps executed locally):** Hardware profile sent to VENZARI Installer Worker at `installer.venzari.xyz`. Plan customized for your tier: binary download, model pulls, docker-compose write, health checks, gateway configuration, SSL, ecosystem wiring, MCP registration. Each step has retry logic.

The install is resumable at any point with `venzari-engine install --repair` — skips completed steps, retries from failure point. Backed by 2,301 automated tests.

> **You've hired your own VENZARI CTO. The installer handles all hard setup and config automatically.**
